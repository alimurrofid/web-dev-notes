# PostgreSQL

> PostgreSQL adalah Object-Relational Database Management System (ORDBMS) kelas enterprise yang terkenal karena keandalan, integritas data, performa tinggi, dan kepatuhan ketat terhadap standar SQL ACID.

---

## Jalur Pembelajaran Terstruktur

1. 🟢 [[postgresql-dasar|PostgreSQL Dasar]] (Modul 1)
   → Instalasi psql, DDL tabel, tipe data relasional, CRUD query dasar, dan foreign key constraints.
2. 🟡 [[postgresql-lanjutan|PostgreSQL Lanjutan]] (Modul 2)
   → INNER/OUTER JOIN, aggregasi GROUP BY & HAVING, Common Table Expressions (WITH), Window Functions, dan B-Tree Indexing.
3. 🔴 [[postgresql-fungsi-administrasi|PostgreSQL Fungsi & Administrasi]] (Modul 3)
   → PL/pgSQL Function, Trigger otomatis, Materialized Views, ACID Transaction Control, dan pg_dump maintenance.
