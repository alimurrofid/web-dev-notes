# Frontend

> Frontend modern menitikberatkan pada perancangan komponen modular yang reaktif, manajemen alur data yang efisien, performa render optimal, dan pengalaman pengguna (_user experience_) yang mulus.

---

## Ekosistem Frontend yang Tersedia

1. **[[Web-Development/Frontend/React/index|React Ecosystem]]**
   → Deklaratif komponen, hooks, client-side routing dengan React Router, dan global state Zustand.
2. **[[Web-Development/Frontend/Vue/index|Vue.js Ecosystem]]**
   → Composition API intuitif, Single File Components (SFC), Vue Router, dan Pinia store.
3. **[[Web-Development/Frontend/Nuxt/index|Nuxt (Fullstack Vue)]]**
   → Framework universal SSR/SSG dengan file-based routing otomatis, data fetching terintegrasi, dan route middleware.
4. **[[Web-Development/Frontend/Angular/index|Angular Ecosystem]]**
   → Framework enterprise terstruktur dengan Standalone Components, reactive Signals, dan client routing bawaan.
