# Vue

> Vue.js adalah framework progresif yang memadukan keramahan belajar pemula dengan performa reaktivitas tingkat tinggi melalui Composition API dan Single File Components (SFC).

---

## Jalur Pembelajaran Terstruktur

1. 🟢 [[vue-dasar|Vue Dasar]] (Modul 1)
   → Single File Component (`<script setup>`), reaktivitas ref & reactive, computed properties, watchers, template directives, dan component props/emits.
2. 🟡 [[vue-router|Vue Router]] (Modul 2)
   → Router setup, RouterView, RouterLink, dynamic routes parameter, route transitions, dan navigation guards autentikasi.
3. 🔴 [[vue-pinia|Vue Pinia]] (Modul 3)
   → Centralized state store resmi Vue, Setup Stores syntax, getters analitis, actions mutasi asinkron, dan integrasi persistent storage.
