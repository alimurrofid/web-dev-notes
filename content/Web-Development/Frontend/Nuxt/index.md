# Nuxt

> Nuxt adalah framework fullstack berbasis Vue 3 yang memberikan fondasi kuat untuk produksi web berperforma tinggi dengan dukungan Server-Side Rendering (SSR), Static Site Generation (SSG), dan auto-import zero-config.

---

## Jalur Pembelajaran Terstruktur

1. 🟢 [[nuxt-dasar|Nuxt Dasar]] (Modul 1)
   → Arsitektur folder convention Nuxt, file-based routing otomatis (pages/), template layouts, auto-imported components, dan SEO head meta tags.
2. 🟡 [[nuxt-state-middleware|Nuxt State & Middleware]] (Modul 2)
   → State management SSR-safe dengan `useState()`, Route Middleware pelindung autentikasi (global vs named), dan runtime plugins.
3. 🔴 [[nuxt-data-fetching|Nuxt Data Fetching & Server API]] (Modul 3)
   → Komposabel data fetching universal (`useFetch`, `useAsyncData`), cache deduplication, dan pembuatan endpoint backend di direktori `server/api/`.
