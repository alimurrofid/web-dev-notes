# Angular

> Angular modern menyederhanakan arsitektur frontend dengan meniadakan NgModule tradisional, beralih penuh ke Standalone Components, dan memanfaatkan Signals untuk reaktivitas bebas zone.js yang sangat cepat.

---

## Jalur Pembelajaran Terstruktur

1. 🟢 [[angular-dasar|Angular Dasar]] (Modul 1)
   → Standalone Components, built-in control flow modern (@if, @for), local signals, input/output binding, dan dependency injection via inject().
2. 🟡 [[angular-routing|Angular Router]] (Modul 2)
   → Konfigurasi Routes, RouterOutlet, routerLink navigation, parameter input binding (:id), lazy loading modul, dan functional route guards.
3. 🔴 [[angular-state|Angular State Management (Signals)]] (Modul 3)
   → Global Signal Service store, computed values derivatif, side effects (effect), HTTP client interaksi, dan sinkronisasi local storage.
