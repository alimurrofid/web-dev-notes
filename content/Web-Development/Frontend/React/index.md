# React

> React adalah library UI berbasis komponen yang paling banyak digunakan di dunia industri. Ekosistem ini mengajarkan cara merancang antarmuka reaktif deklaratif dengan Hooks modern.

---

## Jalur Pembelajaran Terstruktur

1. 🟢 [[react-dasar|React Dasar]] (Modul 1)
   → JSX mental model, functional components, props flow, useState immutability, controlled inputs, dan useEffect lifecycle.
2. 🟡 [[react-router|React Router]] (Modul 2)
   → Single Page Application routing, createBrowserRouter, Outlet bersarang, dynamic URL params (useParams), dan navigasi terprogram.
3. 🔴 [[react-zustand|React Zustand]] (Modul 3)
   → Store creation tanpa provider boilerplate, selector selective rendering (anti lag), async API actions, dan auto-sync LocalStorage persist.
