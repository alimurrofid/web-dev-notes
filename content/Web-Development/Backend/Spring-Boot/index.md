# Spring Boot

> Spring Boot mengabstraksi kompleksitas konfigurasi enterprise Java, memungkinkan developer membangun microservices dan REST API production-ready secara cepat dan teruji.

---

## Jalur Pembelajaran Terstruktur

1. 🟢 [[springboot-dasar|Spring Boot Dasar]] (Modul 1)
   → Inversion of Control (IoC), Dependency Injection (@Component, @Autowired), Application Context, dan Profile konfigurasi.
2. 🟢 [[springboot-web|Spring Boot Web & REST API]] (Modul 2)
   → @RestController, Request Mapping (GET/POST/PUT/DELETE), DTO Validation (@Valid), dan Global Exception Handling.
3. 🟡 [[springboot-jpa|Spring Data JPA & Hibernate]] (Modul 3)
   → Entity modeling, Repository interfaces (JpaRepository), Derived Query methods, JPQL kustom, dan @Transactional rollbacks.
4. 🔴 [[springboot-security|Spring Security & JWT]] (Modul 4)
   → Filter chain architecture, Authentication Manager, stateless token JWT signing & parsing, dan role-based authorization.
5. 🔴 [[springboot-testing|Spring Boot Testing]] (Modul 5)
   → Unit testing dengan JUnit 5 & Mockito, integrasi web slicing via MockMvc, dan database persistence tests.
