# Laravel

> Laravel adalah framework web PHP yang dirancang untuk mempercepat produktivitas developer melalui sintaks ekspresif, ekosistem bawaan yang lengkap, dan ORM Eloquent yang intuitif.

---

## Jalur Pembelajaran Terstruktur

1. 🟢 [[laravel-dasar|Laravel Dasar]] (Modul 1)
   → Arsitektur MVC, routing, Controller logika, Blade template engine, CSRF protection, dan validasi Request.
2. 🟢 [[laravel-database|Laravel Database]] (Modul 2)
   → Database Migrations, Schema Builder, Seeder & Factory data dummy, serta Query Builder yang aman dari SQL injection.
3. 🟡 [[laravel-eloquent|Laravel Eloquent ORM]] (Modul 3)
   → Active Record pattern, Model relasional (1:1, 1:N, N:M), Eager Loading anti N+1 problem, Mutator/Casts, dan Soft Deletes.
4. 🔴 [[laravel-collection|Laravel Collection]] (Modul 4)
   → Transformasi data fungsional berantai (map, filter, pluck, reduce, groupBy), LazyCollection hemat RAM, dan chunking data masif.
