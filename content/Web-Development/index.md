# Web Development

> Pengembangan web modern terbagi menjadi dua ranah utama yang saling melengkapi: **Backend** yang mengelola logika bisnis, data, dan keamanan, serta **Frontend** yang menghadirkan antarmuka pengguna interaktif dan responsif.

---

## Dua Pilar Web Development

- **[[Web-Development/Backend/index|Backend Dev]]:**
  Framework MVC dan REST API yang tangguh:
  - **[[Web-Development/Backend/Laravel/index|Laravel]]:** Framework PHP elegan dan kaya fitur (_batteries included_).
  - **[[Web-Development/Backend/Spring-Boot/index|Spring Boot]]:** Framework Java enterprise performa tinggi dengan skalabilitas masif.
  - **[[Web-Development/Backend/DotNet/index|ASP.NET Core]]:** Web framework cloud-native berkinerja ekstrem dari Microsoft (.NET 10 LTS).
- **[[Web-Development/Frontend/index|Frontend Dev]]:**
  Ekosistem antarmuka web modern:
  - **[[Web-Development/Frontend/React/index|React]]:** Library berbasis komponen dengan ekosistem router & Zustand state.
  - **[[Web-Development/Frontend/Vue/index|Vue.js]] & [[Web-Development/Frontend/Nuxt/index|Nuxt]]:** Framework progresif dengan Composition API dan fullstack universal SSR.
  - **[[Web-Development/Frontend/Angular/index|Angular]]:** Framework enterprise lengkap dengan sinyal reaktif dan dependency injection.
