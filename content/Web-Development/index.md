# Web Development

> Pengembangan web modern terbagi menjadi dua ranah utama yang saling melengkapi: **Backend** yang mengelola logika bisnis, data, dan keamanan, serta **Frontend** yang menghadirkan antarmuka pengguna interaktif dan responsif.

---

## Dua Pilar Web Development

- **[[Web-Development/Backend/index|Backend Dev]]:**
  Framework MVC dan REST API yang tangguh:
  - **Laravel:** Framework PHP elegan dan kaya fitur (_batteries included_).
  - **Spring Boot:** Framework Java enterprise performa tinggi dengan skalabilitas masif.
- **[[Web-Development/Frontend/index|Frontend Dev]]:**
  Ekosistem antarmuka web modern:
  - **React:** Library berbasis komponen dengan ekosistem router & Zustand state.
  - **Vue.js & Nuxt:** Framework progresif dengan Composition API dan fullstack universal SSR.
  - **Angular:** Framework enterprise lengkap dengan sinyal reaktif dan dependency injection.
