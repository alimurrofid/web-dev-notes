# PHP

> PHP modern telah berevolusi menjadi bahasa backend yang sangat cepat, aman, dan berorientasi objek ketat dengan dukungan typing modern, constructor promotion, dan ekosistem Composer yang matang.

---

## Jalur Pembelajaran Terstruktur

1. 🟢 [[php-dasar|PHP Dasar]] (Modul 1)
   → Tipe data dan type hinting PHP 8+, array asosiatif, percabangan match expression, perulangan, dan deklarasi fungsi.
2. 🟡 [[php-oop|PHP OOP]] (Modul 2)
   → Class & Object, Constructor Property Promotion, pewarisan, Abstract Class, Interface kontrak, dan Trait reuse code.
3. 🔴 [[php-standard-library|PHP Standard Library]] (Modul 3)
   → Fungsi manipulasi array bawaan, manipulasi string multibyte, regular expression regex, DateTimeImmutable, dan Exception handling berjenjang.
