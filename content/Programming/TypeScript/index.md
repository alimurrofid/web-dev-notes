# TypeScript

> TypeScript menambahkan sistem pengetikan statis (*static typing*) ke atas JavaScript, mencegah runtime bug sebelum kode dijalankan, serta menghadirkan pengalaman refactoring kode kelas dunia.

---

## Jalur Pembelajaran Terstruktur

1. 🟢 [[typescript-dasar|TypeScript Dasar]] (Modul 1)
   → Type inference, tipe primitif, Type Aliases, Union & Literal Types, Tuple, dan Enum.
2. 🟡 [[typescript-oop-generics|TypeScript OOP & Generics]] (Modul 2)
   → Type contracts Interface vs Type, Class dengan access modifiers (public/private/readonly), dan Generic Functions/Interfaces.
3. 🔴 [[typescript-advanced|TypeScript Advanced]] (Modul 3)
   → Type Narrowing (in, instanceof, type guards), Utility Types (Partial, Pick, Omit), Mapped Types, dan Template Literal Types.
