# Java

> Java adalah bahasa pemrograman berorientasi objek yang kuat, tipe data ketat, dan berkinerja tinggi, digunakan luas dalam sistem perbankan, enterprise backend, dan sistem terdistribusi.

---

## Jalur Pembelajaran Terstruktur

1. 🟢 [[java-dasar|Java Dasar]] (Modul 1)
   → Variabel tipe primitif, operator, percabangan logika, perulangan, dan deklarasi method.
2. 🟢 [[java-oop|Java OOP]] (Modul 2)
   → 4 Pilar OOP (Encapsulation, Inheritance, Polymorphism, Abstraction), Interface, dan Constructor.
3. 🟡 [[java-generic|Java Generic]] (Modul 3)
   → Type-safety kompilasi, Generic Class/Method, Bounded Type Parameters, dan Wildcards (? extends / super).
4. 🟡 [[java-collection|Java Collection Framework]] (Modul 4)
   → Struktur data List (ArrayList, LinkedList), Set (HashSet, TreeSet), dan Map (HashMap, TreeMap).
5. 🔴 [[java-lambda-stream|Java Lambda & Stream API]] (Modul 5)
   → Functional Interface, Lambda Expressions, Method Reference, dan Stream pipeline (filter, map, collect).
6. 🔴 [[java-database|Java Database (JDBC)]] (Modul 6)
   → Koneksi database, Statement & PreparedStatement anti-SQL-injection, ResultSet mapping, dan Transaction management.
