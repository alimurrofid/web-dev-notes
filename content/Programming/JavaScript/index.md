# JavaScript

> JavaScript adalah bahasa pemrograman dinamis yang menghidupkan web. Penguasaan JavaScript modern sangat krusial sebelum melangkah ke framework seperti React, Vue, atau Angular.

---

## Jalur Pembelajaran Terstruktur

1. 🟢 [[javascript-dasar|JavaScript Dasar]] (Modul 1)
   → Deklarasi variabel (let, const), tipe data, coercion, fungsi first-class, dan sintaks ES6+ modern.
2. 🟢 [[javascript-dom|JavaScript DOM]] (Modul 2)
   → Seleksi elemen (querySelector), manipulasi atribut/style, event bubbling/capturing, dan form handling.
3. 🟡 [[javascript-oop|JavaScript OOP]] (Modul 3)
   → Constructor Function, rantai Prototype pewarisan memori hemat, ES6 Class syntax, dan encapsulation privat (#field).
4. 🔴 [[javascript-standard-library|JavaScript Standard Library]] (Modul 4)
   → Manipulasi array tingkat lanjut, pemrosesan String, Object utilities, JSON parsing, Date/Time, dan struktur data modern (Map, Set).
