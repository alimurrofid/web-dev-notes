# C#

> C# adalah bahasa pemrograman modern, type-safe, berorientasi objek, dan berkinerja tinggi yang berjalan di atas runtime .NET 10 LTS, digunakan luas dalam pengembangan enterprise backend, cloud microservices, dan sistem terdistribusi berskala global.

---

## Jalur Pembelajaran Terstruktur

1. 🟢 [[csharp-dasar|C# Dasar]] (Modul 1)
   → Mental model CLR, Top-Level Statements, tipe data value vs reference, nullability, pattern matching switch, dan deklarasi method.
2. 🟢 [[csharp-oop|C# OOP]] (Modul 2)
   → 4 Pilar OOP, Primary Constructors, Field-Backed Properties (`field` keyword C# 14), Records, Structs, dan Interfaces.
3. 🟡 [[csharp-generic|C# Generic]] (Modul 3)
   → Type-safety kompilasi, Generic Class/Method, Generic Constraints, `nameof(List<>)` unbound generics C# 14, dan Covariance/Contravariance.
4. 🟡 [[csharp-collection|C# Collection Framework]] (Modul 4)
   → List, Dictionary, HashSet, Collection Expressions & Spread, dan high-performance memory slicing via `Span<T>`.
5. 🔴 [[csharp-linq|C# LINQ]] (Modul 5)
   → Delegates, Lambda parameter modifiers, Deferred Execution, Operasi LINQ esensial, dan Extension Members block C# 14.
6. 🔴 [[csharp-async-threading|C# Asynchronous & Concurrency]] (Modul 6)
   → Task-based Asynchronous Pattern (`async`/`await`), `ValueTask`, `CancellationToken`, `IAsyncEnumerable`, dan `System.Threading.Lock`.
